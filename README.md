## Como Usar

Copie os arquivos OGG da pasta `assets/audio/sfx/ogg/` para o diretório de áudio do seu jogo.

Cada arquivo segue o padrão de nomenclatura `<categoria>_<ação>_<descritor>_<variante>.ogg`.

### Exemplo

```
player_jump_short_01.ogg
combat_sword_swing_heavy_01.ogg
magic_fireball_cast_01.ogg
```
